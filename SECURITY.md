# Security Policy

This repository documents work performed only in isolated lab environments and on systems owned by the author or explicitly authorised for testing.

## Sensitive information

Do not commit:

- Passwords, API tokens, private keys, or recovery codes
- Personal or confidential data
- Real public IP addresses
- Unsanitised packet captures
- Virtual-machine images or operating-system installation media

If sensitive information is committed accidentally, remove access to the exposed credential immediately, rotate it, and clean the repository history before continuing.
