# Phase 1 — Networking Fundamentals

## Objective

Design, build, and validate the network foundation for the cybersecurity home lab.

## Planned work

- [ ] Review the OSI and TCP/IP models.
- [ ] Create an IP addressing plan.
- [ ] Build a routed topology in Cisco Packet Tracer.
- [ ] Configure switching, routing, and optional VLANs.
- [ ] Test connectivity with `ping` and `traceroute` or `tracert`.
- [ ] Inspect ARP, DNS, ICMP, TCP, and DHCP traffic.
- [ ] Document results and troubleshooting.

## Evidence to collect

- Sanitised topology diagram
- Addressing table
- Configuration excerpts
- Connectivity test results
- Packet-capture observations
- Short reflection on issues and fixes
